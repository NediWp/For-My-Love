# For My Love — G + N

This is the first working prototype of the 30-day love-note site.

## Current setup
- Day 1 begins on August 24, 2026.
- The same link can be used every day.
- Future days are locked automatically.
- Previous/current unlocked days can be opened.
- The opening page, 30-day grid, modal card, and responsive styling are included.
- The notes are placeholders except for Day 1.

## Next step
Replace the placeholder notes in `index.html` with the final 30 messages once the content is written.

## Publishing
This can be published with GitHub Pages, Netlify, or another static hosting service. No database is required for the basic date-based unlocking.
